01Open the app
router.js mounts the view for location.pathname
02Sign up or sign in
POST /api/auth/register or /api/auth/login sets the session cookie
03Choose a file or import a CSV
parseCsv reads the headers and rows in the browser
04Review the detected column mapping
detectMapping resolves headers to recordId, name, category, status, amount, date
05Commit the import
POST /api/datasets, then POST /api/records/bulk
06View the table
sort any column, search, filter by a generated dropdown
07Read the dashboard charts
the panels choose their own columns from the file
08Add, edit or archive a record
POST /api/records, PUT /api/records/:id flips archived
09Delete a whole file
DELETE /api/datasets/:id takes its records with it
columns the six fixed fields do not claim are kept in records.data as jsonb, so the import never drops a header.
the panels profile the keys in records.data and pick a date, a group and a measure, so the charts follow the file.
